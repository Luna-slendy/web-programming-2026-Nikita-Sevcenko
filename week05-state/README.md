# CampusFlow — 5. nedēļa: stāvoklis un formas

Šis ir **CampusFlow** projekta turpinājums. Sākuma punkts ir **jūsu pašu** 4. nedēļas rezultāts (`week04-react`) — atsevišķu sākuma failu šoreiz nav.

4. nedēļā komponentes datus tikai **saņēma** caur props. Šonedēļ tām parādās sava atmiņa — **stāvoklis**. Atgriežas forma *Add a project*, tagad kā **kontrolēta React forma**, un pievienotie projekti atkal saglabājas `localStorage` — caur jūsu pašu uzrakstītu hook `useLocalStorage<T>`.

Dati no API joprojām ienāk tāpat kā 4. nedēļā: `main.tsx` tos ielādē un iedod `App` caur props.

## Faili

- `TASK.md` — praktiskā uzdevuma instrukcija;
- `AI_USAGE.md` — MI izmantošanas apraksta veidne;
- `REFLECTION.md` — individuālās refleksijas jautājumi.

Darbs turpinās tajā pašā GitHub repozitorijā (`web-programming-2026-vards-uzvards`), jaunā mapē `week05-state`.

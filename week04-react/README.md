# CampusFlow — 4. nedēļa: React komponentes ar tipizētiem props

Šis ir **CampusFlow** projekta turpinājums. Sākuma punkts ir **jūsu pašu** 3. nedēļas rezultāts (`week03-api`) — atsevišķu sākuma failu šoreiz nav.

Līdz šim lapu zīmēja jūsu pašu `render.ts` ar `createElement`. Šajā nedēļā to pārņem **React**: lapa tiek salikta no komponentēm, un katrai komponentei ir **aprakstīts props tips**. Datu slānis no 3. nedēļas (`types.ts`, `guards.ts`, `api.ts`) pāriet uz jauno projektu bez nevienas izmaiņas.

React pamatus (JSX, komponentes, props, `useState`) apguvāt pagājušajā gadā ar JavaScript. Jaunais šonedēļ ir **TypeScript**: ko komponente drīkst saņemt, un kas notiek, ja tai iedod ko citu.

# CampusFlow — 6. nedēļa: maršrutēšana un lietotnes struktūra

Šis ir **CampusFlow** projekta turpinājums. Sākuma punkts ir **jūsu pašu** 5. nedēļas rezultāts (`week05-state`) — atsevišķu sākuma failu šoreiz nav.

Līdz šim CampusFlow bija viena gara lapa. Šonedēļ tā kļūst par lietotni ar vairākām lapām un īstām adresēm: Dashboard, Projects, projekta detaļas, Deadlines un 404 lapa. Pāreja starp lapām notiek **bez lapas pārlādes**, un to nodrošina **React Router**.

Dati no API joprojām ienāk tāpat kā iepriekš: `main.tsx` tos ielādē un iedod `App` caur props.

## Faili

- `TASK.md` — praktiskā uzdevuma instrukcija;
- `AI_USAGE.md` — MI izmantošanas apraksta veidne;
- `REFLECTION.md` — individuālās refleksijas jautājumi.

Darbs turpinās tajā pašā GitHub repozitorijā (`web-programming-2026-vards-uzvards`), jaunā mapē `week06-router`.

# CampusFlow — 7. nedēļa: React ielādē datus pats

Šis ir **CampusFlow** projekta turpinājums. Sākuma punkts ir **jūsu pašu** 6. nedēļas rezultāts (`week06-router`) — atsevišķu sākuma failu šoreiz nav.

Līdz šim datus ielādēja `main.tsx`, ārpus React, un pēc katras ielādes izsauca `root.render(...)` vēlreiz. Šonedēļ ielāde pāriet **komponentēs**: ar `useEffect` un pašu hook `useFetch<T>`, kas pieprasījumu arī **atceļ**, kad komponente pazūd. `main.tsx` paliek tikai viens `root.render`.

Klāt nāk arī 6. nedēļā solītais labojums: mainot lapu, tā atveras **no augšas**.
